# Usage Ledger v0.2.36 Source Update

[English guide](../../README.md) | [简体中文说明](../../README.zh-CN.md)

## Changes

- Calculate subscription-month usage from the account's official monthly renewal
  date when available, rather than assuming its original activation day remains
  the billing day. Retain cached account periods after switching sign-ins.
- Match account usage to available request and authenticated quota evidence;
  preserve distinct account identities and do not guess ambiguous ownership.
- Keep subscription and API pricing separate. Apply the supported GPT-6.1 Sol
  subscription long-context exemption without changing API tariffs.
- Include GPT-6.1 Terra model support and the account/pricing fixes accumulated
  since the previous published source version.
- Preserve the original usage overview layout and quota forecast. Remove the
  misleading session-creator suffix from account names.
- Timestamp official quota snapshots when received, not when a later refresh
  reads them. Subscription lookup failures do not discard valid quota updates.
- Missing historical source files no longer prevent quota-evidence recovery
  from other available logs; saved requests are retained.

## Verification and Availability

The Windows desktop build, Vue type check, relevant component tests, native
usage-monitor tests, and copied-ledger reconciliation checks passed locally.
Historical records lacking independent ownership or pricing evidence remain
reference estimates, not verified invoices. Complete GUI visual acceptance is
not claimed.

This is a source update. The published Windows and native Apple Silicon/Intel
Mac downloads remain at [v0.2.25](https://github.com/9holy/usage-ledger/releases/tag/v0.2.25).
Mac packages were not rebuilt or retested for 0.2.36 as part of this push.
Private accounts, credentials, databases, and repair backups are not included.
