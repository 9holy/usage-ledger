# Usage Ledger v0.2.51

Global Usage Monitoring now includes account costs, expenses, procurement channels and API cost rules in the existing workspace. Account, model and call-source summaries share the same saved request evidence and reporting dates.

Source history resumes from a saved cursor after a restart or expired login. Confirmed reset-card events preserve earlier usage and align the next quota cycle automatically. Late local records replace source imports without counting a request twice. Subscription-funded GPT-6.1 Sol usage follows subscription context rules while metered API usage keeps API pricing. Prior API quotations remain available for reconciliation.

Background imports commit small batches and publish quota observations after the last batch. Write transactions acquire their writer slot before reading, unchanged receipts skip repeated pricing, and temporary database contention has bounded recovery. Saved accounts, requests, quotations, expenses and quota history remain local when external logs or source accounts disappear.

Windows, Apple Silicon and Intel packages use the same source. Mac packages use ad-hoc signing without Apple notarization; Windows packages have no Authenticode publisher certificate. Automated startup checks cover the packaged applications, with live billing still depending on available source records. Missing historical quota boundaries are retained as unsegmented usage rather than invented.

## 中文说明

全局用量监控已整合账号成本、费用记录、采购渠道和 API 成本设置，复用同一套请求、账号归属和日期范围。

历史来源记录会保存补采进度，重启或登录续期后自动继续。已确认的重置卡事件会保留此前用量，并自动对齐新额度轮次；迟到的本机记录与来源补录合并，同一请求只统计一次。订阅账号承担的 GPT-6.1 Sol 使用订阅上下文规则，按量 API 仍使用 API 价格，原 API 报价另行保留。

后台补采分批提交，额度快照在最后一批完成后更新。写事务提前取得写权限，未变化的回执跳过重复计价，临时数据库争用可有限恢复。外部日志清理或上游账号消失后，软件已保存的账号、请求、金额、费用和额度历史继续保留。

Windows、M 芯片和 Intel Mac 使用同一版本源码。Mac 使用临时签名，未做 Apple 公证；Windows 没有 Authenticode 发布者证书。缺少真实依据的历史轮次不会补造，已有用量仍保留可查。
