## Monitor mode evidence / 监控模式证据

Codex's first session-mode initialization is treated as initialization, not a mid-turn mode change. A stored misclassification is corrected only when the original committed JSONL prefix or a registered `.zst` record proves the initial mode. Missing raw evidence and genuine conflicts remain unknown. The correction preserves request/token records, saved prices, and quota-cycle facts.

Codex 会话首次设置模式属于初始化，不作为轮次中途的模式切换。只有原始已提交 JSONL 前缀或已登记的 `.zst` 记录能证明初始模式时，才修正历史误分类。原始证据缺失或存在真实冲突时仍保持未知。此修正保留请求/Token 记录、已保存单价与额度周期事实。

## Quota forecasts / 额度预测

Forecasts pair the quota percentage with the accumulated quota amount (the numerator) from the same quota timestamp, account, and cycle. A stale but valid pair is retained with its timestamp. Partial priced amounts are clearly labeled and counted; each unpriced portion has a human-readable reason. A forecast is not a promised final charge.

额度预测会按同一账号、同一周期、同一额度时间戳配对百分比与累计额度金额（分子）。较旧但仍有效的配对会连同时间戳保留。部分已定价金额会明确标注并计数；未定价部分显示可读原因。预测不是最终费用承诺。
