## Optional source export / 可选源码导出

- The optional export command produces `source/`: selected current source, all locales/tests/runtime artwork/icons, locks and build configuration, without Git history.
- `usage-ledger-0.2.24-source.zip` is the same optional export, including dot-prefixed configuration.

These source-export outputs are separate from the installer assets. GitHub's automatic **Source code (zip)** and **Source code (tar.gz)** links are repository snapshots, not installers.

包含多来源成本身份与窗口修复、未知/部分数据状态、中英文成本与监控界面、稳定图例身份，以及 DeepSeek Harness 本地记录支持。可渲染不等于不可得数据已验证，参考金额不等于官方账单。

Includes source-specific identities/windows, explicit missing/partial states, bilingual cost/monitor views, stable legend identities and local DSH records. Rendering does not establish unavailable production data or turn estimates into invoices.

顶部工作区切换按窗口居中，轮次明细补充上次记录的周额度百分比与记录时间。修复旧轮次额度混入当前轮次、同一重置时间下归零导致金额被拆散的问题；保留可确认的提前重置、到期换轮，以及首次达到 100% 后的用量仅计入月累计的规则。

The workspace switcher is centered within the window, and cycle history includes the last recorded weekly percentage and its timestamp. Older-window readings no longer overwrite a confirmed new round, and a zero reading alone does not split its amounts. Evidenced early resets, natural rollover and the first-100% cutoff for month-only extra usage are retained.

English chart peak labels now follow the selected language, currency and display unit. Long toolbar titles remain inside their space, with the full title available on hover. These display fixes do not change amounts, pricing or quota calculations.

图表峰值标注现跟随所选语言、货币与显示单位；较长的工具栏标题不再遮挡返回按钮，悬停可查看完整标题。这两处显示修复不改变金额、报价或额度计算。

A zero reading without distinguishable new-window evidence does not establish another round. Readings incompatible with an accepted boundary do not rewrite it. Historical fragments are not bulk-merged without verification; original requests and saved prices remain unchanged. Targeted event-sequence and amount-conservation regression checks passed; this does not infer reset confirmations absent from the source.

## Rebuild / 构建

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build:desktop
pnpm exec tauri build --config src-tauri/tauri.local.conf.json
```

Windows prerequisites are in the [English README](../../README.md) and [Chinese README](../../README.zh-CN.md). The operator supplies runtime data/services. The local Tauri override omits updater-signature artifacts; signed publication needs the maintainer's private key, never bundled here.

## Desktop Installation / 桌面安装

仅提供手动下载安装包，本版不提供应用内自动更新或便携 EXE。Windows 使用上方 NSIS 安装包；macOS 预览版需按处理器架构选择对应 DMG。不要仅为安装本版而删除用户数据。

Install manually using the NSIS package for Windows or the matching architecture DMG for macOS. No automatic updates are provided by this release, and no portable executable is offered. Do not delete user data just to install this version.

本版保留应用 identifier 与现有用户数据身份，不另建隔离账号/账本目录。安装前备份自己的重要数据，关闭旧实例后再启动新版本，避免两个同身份进程并行使用数据。

The application identifier and existing user-data identity are retained, not replaced with a separate account/ledger profile. Back up important personal data, close the old instance and then start the new version; avoid concurrent processes sharing the same identity.

Windows Authenticode 证书未配置，系统可能显示“未知发布者 / Unknown Publisher”。Tauri updater 的签名用于应用更新校验，不是 Windows 发布者证书，也不意味着可绕过系统安全提示。签名私钥不包含在源包中。

No Windows Authenticode certificate is configured, so Windows may show **Unknown Publisher**. Tauri updater signatures verify application updates; they are distinct from a Windows publisher certificate and do not remove OS security warnings. Signing private keys are not included in the source archive.

The tool refuses existing destinations and never initializes Git, commits or pushes. Exported bytes are verified against the manifest; later source changes require a deliberate new snapshot.
